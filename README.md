The 20G plan is aimed at lightweight workloads:

The 1 GB RAM limit is the main constraint. A minimal Linux installation can run comfortably within that amount, but adding a database, control panel, container stack, and several background services can make the server feel cramped quickly.

## Standard uptime guarantee versus SLA plans

The general VPS page lists a 99.9% uptime guarantee, while BandwagonHost’s separate SLA document applies only to plans that explicitly include an SLA. The SLA document describes a 99.99% monthly uptime commitment for covered VPS instances, subject to exclusions and a claim process.

Those exclusions matter. The SLA does not cover every possible interruption. Problems caused by your operating system, application, configuration, resource usage, attacks, upstream networks, third-party networks, or certain maintenance events may be excluded. DDoS-related traffic filtering or nullrouting is also listed among the exclusions.

Therefore, do not assume that every BandwagonHost VPS carries the 99.99% commitment. Check whether the exact product shown in checkout is labeled as an SLA plan.
